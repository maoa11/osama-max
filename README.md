# لوحة أسامة

منصة شخصية واحدة: الفلوس، عملائي، سلة، المهام، أداء المحتوى، الأهداف.
ملف `index.html` واحد — بدون مكتبات، تشتغل أوفلاين بعد أول فتح.

## الرابط
https://maoa11.github.io/osama-max/

## تفعيل GitHub Pages (مرة وحدة)
1. افتح الريبو ← **Settings** ← **Pages**
2. Source: **Deploy from a branch** ← Branch: **main** ← Folder: **/ (root)** ← Save
3. انتظر دقيقة أو دقيقتين وافتح الرابط فوق

## إضافتها للشاشة الرئيسية
- **آيفون:** افتحها في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية»
- **أندرويد:** Chrome ← القائمة ⋮ ← «تثبيت التطبيق»

> ⚠️ التطبيق المثبّت له تخزين منفصل عن المتصفح (خصوصاً آيفون).
> لو بديت تستخدمها في المتصفح قبل التثبيت: **صدّر نسخة** ← ثبّت ← **استورد** النسخة داخل التطبيق.

## النسخة الاحتياطية
بياناتك محفوظة على جهازك فقط (localStorage) — ما فيه سيرفر.
- **تصدير:** الصفحة الرئيسية تحت ← «تصدير JSON» (أو الإعدادات) — ينزل ملف `lawhat-osama-التاريخ.json`
- **استيراد:** الإعدادات ← «استيراد» ← اختر الملف
- خذ نسخة **كل أسبوع** على الأقل — اللوحة تنبهك لو مر أكثر من أسبوع.
- مسح بيانات المتصفح = ضياع البيانات لو ما عندك نسخة.

## عملائي
من قسم «عملائي» تضيف عميلك الخاص: الاسم، القطاع، الرقم، المبلغ، وطريقة التحصيل (شهري / قطاعي بالقطعة / مرة واحدة).
كل دفعة تسجّلها تنضاف للدخل تلقائياً، واللوحة تحسب لك الباقي عند كل عميل.

## التقارير الشهرية
المزيد ← التقارير (أو زر «التقرير الشهري» في صفحة سلة):
1. اختر العميل والشهر.
2. «هوية العميل»: ارفع اللوقو مرة وحدة وعدّل الألوان (سلة جاهزة بألوانها).
3. أضف وش سويت: النوع، عدد المقاطع، ملاحظة — أو «استيراد الفيديوهات المسلّمة» من خط الإنتاج.
4. «معاينة وتحميل PDF» ← «تحميل PDF» ← في نافذة الطباعة اختر **حفظ كـ PDF**.
   - آيفون: بعد ما تضغط تحميل PDF، اضغط مشاركة ← «حفظ في الملفات».
   - «نسخ كنص» يعطيك ملخص جاهز للواتساب.

## تحديث الملفات
بعد أي تعديل على `index.html` غيّر `VERSION` في `sw.js` (مثلاً `board-v2`) عشان الجوال ياخذ النسخة الجديدة.
